# Archived project documentation

This directory contains early or superseded Dacia Knowledge Base documentation retained for historical context. These files are **not current project instructions, active standards, or authoritative vehicle-data sources**.

| Archived file | Why archived | Current source of truth |
|---|---|---|
| `00_START.md` | Early project entry point | `project/START_HERE.md` |
| `01_MODELE.md`, `02_SILNIKI.md`, `03_SKRZYNIE_BIEGOW.md`, `04_REKOMENDACJE.md` | Earlier Sandero/Stepway-centred scope and purchase guidance | Current versioned source files, `data/master/`, and active documentation listed by `project/START_HERE.md` |
| `PROJECT_CONTEXT.md` | Superseded project overview | `project/AI_WORKING_AGREEMENT.md`, `project/AI_CONTEXT.md`, `project/DECISIONS.md`, and `project/START_HERE.md` |
| `REPOSITORY_STRUCTURE.md` | Stale repository layout | Current repository tree and `project/START_HERE.md` |
| `KNOWN_ISSUES.md` | Obsolete snapshot claiming that core tools, PDF importers and tests were absent | Current repository tree, `project/state.json`, and executable quality checks |
| `DATA_QUALITY_CHECKLIST.md` | Superseded generic checklist that does not describe the current validation gates | `project/QUALITY_AND_SOURCE_VALIDATION_PROTOCOL.md` |
| `DECISION_TEMPLATE.md` | Old ADR-XXXX template inconsistent with the current D-### decision register | `project/DECISIONS.md` and the current decision conventions recorded there |
| `NAMING_CONVENTIONS.md` | Early examples and branch patterns no longer reliable as repository-wide guidance | Current repository conventions, `project/STANDARDS.md`, and `project/DOCUMENTATION_STANDARD.md` |
| `PROJECT_LIFECYCLE.md` | Generic lifecycle duplicated and superseded by the current startup, package and quality contracts | `project/START_HERE.md`, `project/AUTONOMOUS_MAINTAINER.md`, and `project/QUALITY_AND_SOURCE_VALIDATION_PROTOCOL.md` |
| `CHANGELOG_PROJECT.md` | Partial supplementary log with early project setup entries and some package notes overlapping the canonical changelog | Root `CHANGELOG.md` is the canonical project-wide change history; this earlier log is retained only as a historical supplement |

The archived Sandero/Stepway descriptions and recommendations reflect an earlier project scope and may be outdated. Do not use them to populate current data or guide current vehicle recommendations without checking current official sources.

The archived governance documents are retained as historical records only. Do not follow their old checklists, branch examples, sprint cadence, decision identifiers or lifecycle sequence in place of the current documents above.
