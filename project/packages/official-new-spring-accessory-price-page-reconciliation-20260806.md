# Official New Spring Accessory Price and Page Reconciliation

Date: 2026-08-06

## Goal

Assimilate the complete official Polish New Spring accessory price list valid from 2024-04-17 and reconcile its rows with the current official Spring accessory page and selected Dacia Shop product cards, without using the configurator.

## Result

- 56 complete price-list rows;
- five rows marked as requiring installation;
- 12 concepts promoted on the current Spring accessory page;
- nine current-page concepts linked to a document reference;
- three current-page concepts kept without a verified reference;
- 11 current shop corroboration records;
- one shop-only rubber-mat reference absent from the 2024 document.

## Source layers

The 2024 price list supplies part numbers, VAT-inclusive prices without installation and printed installation markers. The current model page supplies the currently promoted concepts. The shop supplies only the compatibility, price and availability shown on each retrieved card.

A document price is not automatically treated as the current dealer price. Absence from shop search is not treated as withdrawal.

## Important findings

- The current page promotes a MagSafe 15 W charger, a 3D cup holder and a YouClip bag without exposing part numbers; similarly named document rows were not substituted.
- The V2L concept is linked to `296976446R`, whose document description is “adapter for powering external equipment”.
- Two different Comfort/Premium textile-mat pairs remain separate because the document provides different references without a distinguishing note.
- The current shop exposes rubber mats `749M68749R`, while the document contains `8201756618` and `8201756621`; no equivalence is inferred.
- The front trunk, armrest, decorative roof rails, double boot floor, reversible boot liner and several YouClip accessories are retained with their document references.

## Boundaries

- No configurator data.
- No cross-model or cross-market transfer.
- No part-number inference from visual similarity or a generic marketing name.
- No historic price described as current without shop corroboration.
- No duplicate-looking rows collapsed without official evidence.

## Next step

Build a cross-model coverage and missing-data matrix for colours, wheels, equipment, packages and accessories. Only gaps that remain after all official documents, model pages and shop records will enter the bounded configurator fallback queue.
