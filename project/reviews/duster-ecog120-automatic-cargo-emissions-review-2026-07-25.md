# Duster Eco-G 120 Automatic Cargo and Emissions Review — 2026-07-25

## Reviewed evidence

The official Polish Duster MY26 price list effective 3 July 2026 contains a dedicated `Eco-G 120 auto` technical column. Its luggage rows state `439` without a spare wheel and `1373` as maximum luggage capacity. The document uses the ISO 3832 capacity basis represented by the existing canonical attributes.

## Decision

Import both catalogue values for the three exact active Eco-G 120 automatic configurations:

- Expression;
- Extreme;
- Journey.

Use `cargo_volume_without_spare_wheel_iso3832` and `maximum_cargo_volume_iso3832`. Do not map the values to `cargo_volume_vda`, `boot_capacity`, luggage-cover height or seat-back height.

## CO2 conclusion

The catalogue prints one `123 g/km` value for the bi-fuel automatic column without an explicit petrol/LPG qualifier. Exact Polish stock-card evidence already supplies LPG CO2. The catalogue therefore does not support a distinct petrol CO2 record and must not be used to manufacture one.

## Boundaries

- No manual cargo values are inherited.
- No conversion between ISO 3832, VDA or liquid litres is performed.
- No trim-dependent cargo difference is invented; the source column applies to the exact automatic powertrain and the three registered catalogue trims.
- No petrol CO2 observation is imported.
- Prices, equipment and mass values remain owned by their existing packages.

## Result

The luggage-volume gap is closed with six source-backed observations. The petrol CO2 gap remains intentionally unresolved. The next source package is the registration and conservative gap review of the five official brochures supplied by the project owner.
