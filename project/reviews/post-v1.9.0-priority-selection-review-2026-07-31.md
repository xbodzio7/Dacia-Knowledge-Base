# Post-v1.9.0 Priority Selection Review

Date: 2026-07-31

## Decision

Select `Cross-Model Navigation Usability Review` as the next bounded package.

## Why now

The v1.9.0 publication cycle is complete and independently audited. The cross-model product now covers 78 configurations, 20 scopes and 80 generated comparison paths, while the previously deferred usability question remains unresolved: whether ordinary consumers can discover that product directly from the deterministic offline workspace.

The selection is consistent with the roadmap direction to improve report usability without changing data semantics. It also avoids reopening completed residual evidence boundaries or starting a broader model expansion before source intake is defined.

## Review-only contract

The next package will inspect the current workspace index, cross-model navigation HTML, consumer guide and release audit. It will produce a factual discoverability assessment and one minimal implementation recommendation.

It will not change:

- source or master data;
- reporting scopes or pair generation;
- ranking, recommendation or inference behavior;
- public v1.9.0 assets;
- interface code during the review itself.

## Expected follow-up

A later implementation package may be proposed only when the review identifies a concrete, testable discoverability gap. Its manifest must be derived from the review evidence rather than assumed in advance.
