## Decision

The next package is **Spring Official Source Intake Review**.

Spring is already a current canonical model, but the registered source catalogue contains no Spring source. At the same time, Dacia Poland currently exposes an official Spring configurator, an official brochure download entry point and exact MY26 stock cards.

1. **Spring Official Source Intake Review — selected.** High value and high readiness. It fills a model-level source gap without requiring a new schema or reopening completed work.
2. **Additional reporting expansion — deferred.** The known cross-model navigation gap is closed and no equally concrete reporting defect is recorded.
3. **Verified PDF residual continuation — deferred.** No new evidence makes a closed residual boundary import-ready.
4. **Immediate data-products release — deferred.** No source-backed data or product delta currently justifies a new immutable release.

## Review boundary

The selected package will not register a source, archive a binary, create a normalized snapshot or import values. It will only select the exact official Spring source set and define the smallest reproducible follow-up package.

## Required distinctions

The review must keep three evidence classes separate:

- an immutable official document suitable for document date and SHA-256 registration;
- dated dynamic configurator observations whose grade and powertrain applicability is explicit;
- exact stock-card evidence that must not be generalized to other configurations.
