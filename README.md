# Dacia Knowledge Base (DKB)

Dacia Knowledge Base (DKB) to referencyjna baza wiedzy o samochodach marki Dacia.

Projekt gromadzi ustrukturyzowane dane dotyczące modeli, wersji wyposażenia, silników, skrzyń biegów, wyposażenia, danych technicznych oraz źródeł informacji.

<!-- dkb:documentation-baseline:readme:start -->
Zweryfikowany model obejmuje 1927 testów, 47 pliki CSV, 16911 rekordów
danych, 51 relacje między tabelami, 6682 wartości konfiguracji, 139 skalarnych specyfikacji importu, 345 zakresów konfiguracji i 24
specyfikacji zakresów oraz 7286 rekordów dostępności wyposażenia.
Katalog zawiera 416 kanonicznych atrybutów i 30 kategorii atrybutów. Baza
SQLite obejmuje 47 tabele i 16911 rekordów, pozostaje zgodna z CSV, a wszystkie
źródłowe pliki CSV są zapisane jako UTF-8.
